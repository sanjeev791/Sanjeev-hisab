# Sanjeev Hisab Android App

This is a minimal Android WebView project wrapping the Sanjeev Hisab HTML app.

## GitHub phone build
1. Upload the **contents** of this folder to the repository root (not the ZIP itself).
2. Open GitHub > Actions.
3. Open **Build Sanjeev Hisab APK**.
4. Tap **Run workflow** (or push to main/master).
5. When complete, open the run and download the artifact `sanjeev-hisab-debug-apk`.

Note: Ads, billing, signing, privacy policy, and Play Store release configuration still need to be added before publishing commercially.
