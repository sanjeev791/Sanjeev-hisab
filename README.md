# Sanjeev Hisab Android App

This is a real Android Studio project wrapping the Sanjeev Hisab HTML app in a native Android WebView.

## Build APK on GitHub (phone-only)
1. Upload all files and folders in this project to the root of your GitHub repository.
2. Open the repository's **Actions** tab.
3. Select **Build Sanjeev Hisab APK**.
4. Tap **Run workflow** (or push to main/master to trigger it).
5. When finished, open the workflow run and download the artifact named `sanjeev-hisab-debug-apk`.

This creates a debug APK for testing. A signed release AAB is required for Play Store publishing.
